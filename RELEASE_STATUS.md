# Restoration source release · rc40

This public source update packages the restored experimental candidate and its required cumulative Hermes host patch. It is not a catalog acceptance, automatic upgrade, stable release or installed-user acceptance result.

## Restored

Scoped private/project review; source review and capture controls; read-only wiki; lexical search; chat-folder management; important-message highlighting/timeline; whole-message presentation settings; six original native starter skills; separate organizer/search preferences; credential/consent and routing-readiness surfaces; eligible-native-install update policy controls.

## Not finished

- Production organizer transport remains disabled (`_TRANSPORT_FACTORY = None`). Parser, provider-envelope and consent/dispatch foundations are not a qualified live organizer. Model aliases and request profiles still need qualification.
- There is no autonomous model-backed search agent. Local lexical search and model settings do not substitute for that agent.
- No memory-derived skill generation, general model-routing database, automatic stuck-detection agent, cross-app integration or core redesign is claimed.
- No clean end-user Windows/Electron acceptance or real-provider run was completed. Synthetic UI/controller tests are not screenshots of an installed plugin.
- Auto-updates are ineligible for this manual-copy candidate. Do not assume it updates itself on startup.

## Known usability limits

Message styling is off by default. Markers stay visible in Markdown/copy output; ambiguous multipart messages are deliberately not classified. Presentation settings are installation-local and shared across Desktop profiles. Folder metadata does not grant project-memory access. Stores are bounded plaintext. Use a fresh disposable profile, not old private data.
