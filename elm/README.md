# ELM scoped-memory restoration candidate · rc40

**Experimental source release requiring the exact accompanying patched Hermes host. Not a stock drop-in plugin.**

The installable directory is this `elm/` folder. Start with the [installation guide](docs/CANDIDATE_INSTALL.md), [repository overview](../README.md), [current release status](../RELEASE_STATUS.md) and [test report](../TEST_REPORT.md).

## Included

Authenticated private and separately consented project records; pending/approved lifecycle; source/excerpt review; opt-in local capture and private request recall; optional local lexical search; scoped read-only wiki; separate organizer/search settings; native starter skills; chat folders; important-message markers/timeline; whole-assistant-message categories and bounded visual customization.

## Important boundaries

Production organizer extraction is disabled. An autonomous model-backed search agent is not implemented. Credentials/preferences/consent controls and synthetic dispatch tests do not prove live provider operation. No model-facing ELM tools or legacy draft command are registered.

Chat folders are metadata only, not filesystem workspaces or project permissions. Six starter skills are original static procedures, not skills generated from your memories. The manual-copy installation cannot enable automatic updates. Message categories are off by default; source markers remain visible and “Final” does not verify success.

Installing the plugin does not grant capture, recall or project access. Select/enable each explicitly. Local stores are plaintext; do not treat them as a secret vault. No automatic adoption/migration of old stores is supported. Retained legacy modules and archived documentation are provenance, not active installation instructions.
