# r20 selected-export reviewed copy

No automatic migration, legacy roots, global data scan, arbitrary path or file browser. The current private-chat UI accepts a user-pasted JSON selected export, maximum 65536 UTF-8 bytes. Format elm-selected-records-v1 contains 1–8 selected records with id/title/text/sources and optional allowed legacy metadata. A separate right-to-copy checkbox is mandatory before preview; it is a user declaration, not verified ownership or authorship.

Authenticated private.import.preview returns full normalized candidates plus original claims, raw/canonical hashes and current-private destination. Confirmation displays the exact original JSON and every normalized candidate/claim without truncation, including old approval/classification versus new pending/sensitive/reference classification. Unknown/unsupported fields, nonempty dependencies, linked-record and reserved private-snapshot references are rejected by the backend, not silently discarded. A declared-export provenance reference is added; it proves only the supplied export identity.

Final human confirmation uses the immutable reviewed server token and current authenticated owner, never a reread of the form. No originals are read, changed, overwritten or deleted. Copies receive fresh IDs. All remain pending and sensitive; final approval is separate. No model call or project adoption.

Private import.list/get receipt inspection provides hashes and array-aligned original claims/new record IDs for reconciliation. Lost apply outcomes are uncertain and not automatically retried. Exact ordered canonical batch idempotence is not general duplicate detection: edited, subset or reordered exports may create duplicate copies. Receipts prove a copy, not current record approval. Current scope changes clear receipts/previews and invalidate late completions. No sensitive source or preview token is cached persistently by the UI.

Verification: 75 controller tests, including five new import tests, and eight actual React SSR suites with synthetic adapters. private-import-review.html is real component rendering with synthetic data, not a native installed screenshot. Tests cover explicit declaration, raw+normalized review, private-only routing, exact confirmation/owner binding, receipt reconciliation, escaped untrusted content and token exclusion. No browser bypass, live installation/publication, external or paid API calls.
