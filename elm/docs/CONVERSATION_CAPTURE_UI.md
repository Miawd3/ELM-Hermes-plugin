# r14 opt-in local conversation capture

Private page only. Separate from automatic recall settings: explicit status refresh, draft enable/disable and caps, server preview, final human confirmation. No construction-time read/write, no provider selection, no paid API calls, no record approval or model egress consent. Existing private setup and supported authenticated native host capture path are required; stored enabled is not proof capture occurred.

RPCs are `plugin.elm.private.capture_settings.status/preview/apply` and `private.capture.list`. Every request supplies only current session identity to the authenticated host, not caller-defined owner namespaces. Final apply uses the reviewed one-use token. Captured-turn list contains IDs/counts/phase, not bodies. Separate reveal uses existing `private.source.get`; exact excerpt preview/apply and withdrawal use the existing reviewed private-source operations. The private review must first be refreshed to establish initialized-store visibility.

User and assistant source snapshots remain sensitive. Native receipt displays admission, role, `finalized_before_delivery` phase and `secret_redacted_native_text` representation as inert text. This is neither complete transcript, verified truth, verified authorship nor proof the assistant answer was delivered. Exact excerpts remain pending and inherit sensitivity. No automatic extraction, declassification or approval.

Limits: 1–32 retained turns (default 8), 2048–32768 combined redacted user plus assistant UTF-8 bytes per turn (default 16384), not tokens or aggregate retained bytes. Backend is authoritative for exact admission/size accounting. Caps stop new capture, not rolling expiry. Withdrawn sources still count and retain bytes. No permanent purge. Enabling/settings changes exclude already queued/in-flight admissions. Disabling does not erase snapshots or other transcripts/output/backups. Existing shared source-count and manifest-byte capacity also applies. Remaining turn allowance is not guaranteed shared capacity. The backend capacity_reason is displayed as inert text, without other-chat counts.

The controller freezes drafts and binds final clicks to the exact displayed action and owner context. Settings object identity prevents old rendered forms staging after refresh. Late replies are discarded on scope/socket/generation change. Lost mutation results are uncertain and not replayed. Refresh settings plus the private review to reconcile before intentionally staging again; settings read alone never clears global mutation uncertainty. Unavailable/archived project bindings can still block private operations; explicitly unbind before retry rather than bypass authority.

Evidence: 57 controller tests, including 10 conversation-capture tests. Five real React SSR suites (synthetic SDK/theme adapters); `private-conversation-capture.html` demonstrates actual component rendering, not native Desktop acceptance. No browser sandbox bypass or new browser success claim, no publication or live install.
